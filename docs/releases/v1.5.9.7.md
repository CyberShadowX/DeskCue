# DeskCue 1.5.9.7

- 修复开机时 Explorer 尚未就绪可能触发的管理员权限误报；无法确认桌面权限时等待有限时间后保留当前应用。
- 重启前重新核对当前会话的实际 Shell 及其令牌权限，完整传递启动参数；无法安全重启时保留当前应用。
- 提供显式运行的旧版 DeskCue 开机任务修复工具：先预览并核对归属，备份后才修改匹配的旧任务。
- 管理员模式提示准确说明部分 WinUI 拖拽和原生应用通知的限制，保留任务编辑、现代附件选择器和现有托盘提醒回退方式。
