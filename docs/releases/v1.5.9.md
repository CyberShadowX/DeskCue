# DeskBox 1.5.9

The polish release. The file right-click menus move to the Windows 11-native shape with an "Open with" submenu, "New"/"View"/"Sort by" submenus, and native ZIP support. Korean joins the language roster alongside a full translation-quality pass over all twelve existing languages. The first-run experience is redesigned with a logo assembly animation and a file-drop scene, Shell locations (Recycle Bin, This PC) drop into boxes as shortcuts, and under the hood widget placement survives display-topology changes via a deliberate-placement timestamp arbitration, edge-docked bars no longer jump to a corner on reveal, group-tab capsules expand promptly after a member swap, and the idle-memory reclaim returns to the "five seconds after you stop touching it" behavior.

Scope note: the System Monitor widget under development on `feat/system-monitor-widget` is **not** part of this release; every non-monitor change from that line ships here.

Release date: TBD (content prepared from the `release/1.5.9` branch — all non-monitor work from `feat/system-monitor-widget`, rebased onto `main`).

## Highlights

- **Korean language support.** The interface, installer, and first-run experience ship in Korean alongside the existing 12 languages, plus a full translation-quality pass over the 1.3.8-era machine translations in es/ar/ru/hi/bn/fr and the other locales.
- **Windows 11-native right-click menus.** Icon strip plus Microsoft-terminology rows; "Open with" lists real associated apps including UWP with icons; "New"/"View"/"Sort by" submenus on the blank area; native ZIP compress (tar variants, multi-select) and extract.
- **Shell locations drop into boxes as shortcuts.** Recycle Bin, This PC, and similar Explorer locations become working shortcuts when dropped on a box, with toast feedback for empty or busy sources.
- **A redesigned first-run experience.** Three-piece logo assembly animation, a file-drop scene, and the real managed storage path with move/paste hints.
- **Steadier widgets.** Placement survives display-topology changes (a stale snapshot can no longer overwrite the user's latest placement), edge-docked bars stop jumping to a corner on reveal, group-tab capsules expand promptly on re-entry, and the minimum expanded size halves to 25 DIP.

### 主要更新

- **新增韩语界面。** 界面、安装器与开屏引导新增韩语，与既有 12 种语言并列；同时对 1.3.8 时期机翻事故（es/ar/ru/hi/bn/fr 等）做全量译文修正。
- **Windows 11 原生右键菜单。** 图标条 + 微软术语行；「打开方式」列真实关联应用（含 UWP 带图标）；空白处「新建」「查看」「排序」子菜单；原生 ZIP 压缩（tar 变体、多选）与解压。
- **Shell 位置拖入格子即建快捷方式。** 回收站、此电脑等拖到格子上直接创建可用快捷方式；来源无内容或正忙时给出 toast 提示。
- **开屏引导全新改版。** 三块拼片 logo 组装动画开场，文件投放场景演示，展示真实托管存储路径及移动/粘贴提示。
- **更稳的格子。** 位置扛住显示器拓扑变化（过期快照不再覆盖用户最新摆放），贴边长条不再跳角，分组胶囊切标签后即时展开，展开最小尺寸减半至 25 DIP。
