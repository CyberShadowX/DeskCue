# DeskCue 1.5.9.4

## 中文说明

本版修复 MyDockFinder Finder 托盘菜单窗口已创建，却被 DWM / Shell 隐藏且定位偏离点击位置的问题。

- 菜单以实际点击位置为准，只有托盘图标位置与点击所在显示器一致时才使用图标锚点。
- 在有限时间内检查实际打开的菜单宿主；确认被 DWM 隐藏时，先关闭该宿主，再使用原生菜单兜底。
- 应用开始退出后不再执行延迟的菜单呈现回调，避免退出过程中重新唤起菜单。
- 保留全部现有托盘菜单命令，并在发布历史中保留 DeskCue 1.5.9.3。

DeskCue 派生自 [Tianyu199509/DeskBox 1.5.9](https://github.com/Tianyu199509/DeskBox/tree/1fdf0bd9f84affe889318173a7f3141843c79604)，遵循 GPL-3.0-only，保留上游版权、第三方声明与来源归属。

安装包、源码及实际 SHA-256 校验值以 [v1.5.9.4 发布资产](https://github.com/CyberShadowX/DeskCue/releases/tag/v1.5.9.4)和随附的 `SHA256SUMS.txt` 为准。本说明不代表 Native AOT 打包、ARM64 或最终零售版 GUI 验收已通过。

## English

This release addresses a MyDockFinder Finder tray menu whose window was created but remained DWM / Shell-cloaked and positioned away from the click.

- Anchor the menu to the actual click; use the tray icon bounds only when they agree with the click's monitor.
- Probe the currently open menu host within a bounded interval. If DWM reports it cloaked, close the hidden host before opening the native fallback menu.
- Stop deferred presentation callbacks during application shutdown so they cannot reopen the menu while exiting.
- Retain every existing tray menu command and keep DeskCue 1.5.9.3 in the release history.
