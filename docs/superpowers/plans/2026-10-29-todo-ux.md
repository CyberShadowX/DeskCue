# Todo UX Implementation Plan

> **For agentic workers:** Use superpowers:subagent-driven-development task by task.

**Goal:** Make the Todo widget fit its list, show note previews, and edit notes with one click.

**Architecture:** Keep raw Markdown and the existing autosave editor. Project a cached plain-text note preview into each list row. Measure natural list content at its current width and request height through an optional content-to-host contract; the host owns DPI, work-area caps and bounds persistence.

**Tech Stack:** WinUI 3, .NET 10, C#, xUnit, Native AOT, project-local PowerShell tooling.

**Spec:** Approved user request in this chat on 2026-10-29, recorded below.

## Global Constraints

- All project-owned tools, worktrees, fixtures, caches and evidence stay under F:\AI\AIProjects\DeskCue.
- Preserve user data, upstream functionality, copyright and GPL attribution. Use generic synthetic tasks in evidence committed publicly.
