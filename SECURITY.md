# Security Policy

**English** | [中文](#中文)

## English

### Supported versions

Please check the fork's [Releases](https://github.com/CyberShadowX/DeskCue/releases) before reporting and include your DeskCue version. Security fixes and release timing are assessed by the fork maintainer; no response or fix deadline is promised.

### Reporting a vulnerability

Keep vulnerability details private:

1. Open the fork's [Security page](https://github.com/CyberShadowX/DeskCue/security). **If** GitHub offers **Report a vulnerability**, use that private form. This policy does not claim that private reporting is enabled.
2. If that form is unavailable, open an [Issue](https://github.com/CyberShadowX/DeskCue/issues) containing only a request for a private contact channel. **Do not include vulnerability details, reproduction steps, logs, screenshots, or personal data in that public request.** Wait for a private channel before sharing them.

Once a private channel is available, describe what you found, the possible impact, and reproduction steps. Remove credentials and unrelated personal information. No email address or upstream-author contact is designated for DeskCue reports.

### Scope notes

Reports about this fork's application, installer, updater, or optional WebDAV backup client are in scope. DeskCue is derived from [DeskBox](https://github.com/Tianyu199509/DeskBox); upstream authorship and GPL attribution remain in [UPSTREAM.md](UPSTREAM.md). The upstream author's private contact and services are not DeskCue support channels.

## 中文

### 支持版本

报告前请查看本分支的 [Releases](https://github.com/CyberShadowX/DeskCue/releases)，并注明 DeskCue 版本。修复和发布时间由分支维护者评估，不承诺固定响应或修复期限。

### 如何报告漏洞

请保持漏洞细节私密：

1. 打开本分支的 [Security 页面](https://github.com/CyberShadowX/DeskCue/security)。**如果** GitHub 提供 **Report a vulnerability**，请使用该私有表单。本文不表示该功能已经启用。
2. 如果没有该表单，可在 [Issue](https://github.com/CyberShadowX/DeskCue/issues) 中**仅请求提供私密联系渠道**。**公开请求中不要包含漏洞细节、复现步骤、日志、截图或个人数据。** 等待私密渠道建立后再提供这些内容。

在私密渠道中说明发现、可能影响及复现步骤，并移除凭据和无关个人信息。DeskCue 未指定任何报告邮箱，也未将上游作者的联系地址作为本分支报告渠道。

### 范围说明

本分支应用、安装器、更新器及可选 WebDAV 备份客户端均属于报告范围。DeskCue 派生自 [DeskBox](https://github.com/Tianyu199509/DeskBox)，上游作者及 GPL 归属见 [UPSTREAM.md](UPSTREAM.md)。上游作者的私人联系方式和服务不属于 DeskCue 支持渠道。
